# Simulador Concurrente de Pedidos - NovaTech

Este proyecto es una aplicación de consola desarrollada en **Python** que simula el procesamiento concurrente de pedidos para una tienda de tecnología, garantizando la integridad de los datos mediante el uso de hilos (Threads) y exclusión mutua.

## Requisitos y Herramientas
* **Lenguaje:** Python 3.x (Probado en Python 3.9+)
* **Dependencias:** Ninguna (solo utiliza librerías estándar como `threading`, `queue`, `time`, `random`).
* **Sistema Operativo:** Windows / Linux / macOS.

## Instrucciones de Ejecución (Reproducibilidad)
1. Descargue el archivo `novatech_threads.py` en una carpeta de su computadora.
2. Abra una terminal o consola de comandos en esa ubicación.
3. Ejecute el siguiente comando:
   ```bash
   python novatech_threads.py
